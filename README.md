# Task API

A RESTful Task Management API built with **Node.js** and **Express**.

This project provides CRUD operations for managing tasks, uses **in-memory storage**, and includes **Swagger UI documentation** for exploring and testing the API.

## Features

- Create tasks
- Retrieve all tasks
- Retrieve a single task by ID
- Update tasks
- Delete tasks
- API documentation with Swagger UI
- Health check endpoint
- JSON-based REST API

---

## Tech Stack

- Node.js
- Express.js
- Swagger UI Express
- Swagger JSDoc
- Nodemon (development)

---

## Installation & Running

Clone the repository:

```bash
git clone <your-repository-url>
```
Navigate into the project directory:
```bash
cd task-api
```
Install dependencies:
```bash
npm install
```
Run the application:
```bash
npm run dev
```
The API will start on:
http://localhost:3000

Swagger documentation is available at:

http://localhost:3000/api-docs
